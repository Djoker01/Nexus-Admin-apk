# Nexus Admin

Sistema de administración para pequeños negocios - Aplicación Android Nativa

## 🚀 Cómo compilar

Este proyecto se compila automáticamente con GitHub Actions. Solo necesitas:

1. Crear un repositorio en GitHub
2. Subir todos los archivos
3. Ir a la pestaña "Actions"
4. Ejecutar el workflow "Build Nexus Admin APK"
5. Descargar el APK desde los artifacts

## 📱 Características

- Dashboard con KPIs en tiempo real
- Gestión de inventario con alertas de stock
- Registro de ventas
- Control de caja
- Gestión de gastos
- Cuentas por cobrar
- Control de mermas
- Reabastecimiento
- Análisis de proveedores
- Reportes
- Respaldos de datos

## 🛠️ Tecnología

- Kotlin + Jetpack Compose
- Room Database (offline)
- Material Design 3
